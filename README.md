# HCI-final-project
This is a repository for my final project in my HCI class. I have changed the names to hide the names of the people invled. Please read the README.md for more detials

The class structure till this point was to work through the first iteration as a class and then the final was a group project to either do a second iteration or a first iteration in the design process for something new. 

I chose to do a second iteration and I worked alone on the project. 

Names have been removed from all things to protect peoples privacy
